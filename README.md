A program that writes one funny line — a gym member who promised to be back tomorrow in 2019, and the treadmill that still sends "u up?" texts like an ex — to `/output/entry.txt`. Two sentences, 107 characters, deterministic: the same bytes on every run. Built by an AI agent for make.fun's "One Line, One Laugh" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
